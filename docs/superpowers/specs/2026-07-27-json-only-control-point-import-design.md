# 本地控制点仅支持 JSON 导入设计

## 目标

将手动控制点的数据导入统一为 JSON，移除 Markdown、文本文件等本地文件格式，降低文件选择和错误提示的理解成本。

## 方案

采用完整的 JSON-only 方案，而不仅是修改按钮文案：

- 本地文件按钮显示“读取本地 JSON”。
- 文件选择器仅接受 `.json`。
- 输入编辑区标题改为“JSON 控制点”。
- 解析器只调用 JSON 解析逻辑，不再尝试 Markdown 表格或文本行解析。
- 空输入、格式错误和控制点不足的提示只描述 JSON。

仅修改文件扩展名过滤但保留 Markdown 解析会造成界面与实际能力不一致；保留 Markdown 入口则不满足“不要 MD”的要求，因此不采用。

## 保持不变

- JSON 数组、`controlPoints` 和 `waypoints` 三种现有 JSON 结构继续支持。
- 路线名称、控制点编辑、自动推荐及手动路线生成逻辑不变。
- 用户仍可在“输入数据”区域粘贴 JSON。

## 验收

- 页面不出现 `JSON/MD`、`Markdown`、`.md`、`.markdown` 或 `.txt` 文件类型。
- Markdown 表格输入返回 JSON 格式错误。
- 现有 JSON 导入测试继续通过。
- 完整测试与生产构建通过。
