# 道路智能选型系统 — 开发计划

## 目标
把系统从"路线评价系统"升级成"道路智能选型系统"。

## 开发步骤

1. **路网数据导入** — 武汉 OSM/SHP/GeoJSON 路网 → 程序可读格式
2. **路网图构建** — 道路拆成节点（路口）和边（道路段）
3. **道路属性计算** — 长度、坡度（DEM叠加）、道路等级、桥梁、绿道、窄路、转弯角
4. **选线约束** — 起点、终点、必经点、避让区
5. **自动生成候选路线** — 搜索算法在路网上找 42km 合规路径
6. **接入现有系统** — 生成的路线自动进入评分、地图、对比、导出

## 当前状态

- 步骤 1：待找数据
- 步骤 2：待开发 — **纯算法，不依赖真实数据**
- 步骤 3：待开发 — 需要 DEM + 路网
- 步骤 4：待开发 — 约束条件定义
- 步骤 5：待开发 — **核心算法，不依赖真实数据**
- 步骤 6：待接入 — 需要了解现有数据接口

## 现有系统边界

- `src/domain/routeMetrics.ts` — `MarathonRoute` 接口定义，自动生成的路线需要实现该接口
- `src/data/routes.ts` — 当前预置路线，未来由算法生成替代
- `src/domain/routeMetrics.ts` — `scoreRoute()` / `compareRoutes()`，生成的路线直接喂入评分
