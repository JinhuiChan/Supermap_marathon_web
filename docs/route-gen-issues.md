# 路线生成算法 — 已知问题

## 当前状态
贪心随机游走 + BFS闭路算法能生成路线（曾产出39km和41km），但存在精度问题。

## 已尝试但失败的方案

1. **Dijkstra闭路** — 最短回路距离由路网结构决定，无法控制，总长跳过容差窗口
2. **邻域枚举闭路** — 当前节点的出边+Dijkstra组合永远命不中±2km窗口
3. **DFS剪枝** — 69节点图上搜索空间太大，visited限制导致路径耗竭，无限制则步数爆炸
4. **绕路扩展**（最短路径+detour）— 最短路径16km，需补25km，单次绕路不够，多次绕路则组合爆炸
5. **距离预算回溯** — 未被完整实现

## 根因分析
- 路网边长为2-3km，步长粗，42.195km精确命中概率低
- 闭路距离不可控（BFS按边数最短，Dijkstra按距离最短），无法微调
- 游走一旦超过目标就无法回头

## 待尝试
- 游走+局部BFS枚举所有闭路可能（当前节点2-3步范围内搜索到终点的多条路径，选最优匹配）
- 模拟退火：随机游走生成初始路径，通过局部修改（换一段路）优化总长
- 后处理微调：先生成40km左右的粗路径，再在路径上插入/删除小段微调至42.195km
